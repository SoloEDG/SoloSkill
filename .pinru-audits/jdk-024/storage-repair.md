# 手记读取失败时保护原始数据

读取到损坏 JSON、未知版本或字段校验不通过的本地手记时，当前 `loadGame` 返回新手记，`useGame` 的自动保存 effect 随即把新手记写回同一个键。预期为保留原始字符串，并允许本次临时游玩。

最小修复是在加载结果中标记恢复状态，由现有自动保存入口保留本次会话的写保护。新用户及有效版本 1 存档继续自动保存。临时会话的提示明确说明原手记已保留。

回归验证通过真实 `useGame` 的 React effect 路径，分别覆盖损坏 JSON、未知版本、字段错误、读取异常、有效存档、新用户和写入失败。临时会话继续修改装备后也不能覆盖旧数据。测试工具和运行输出放在项目外，避免进入评测基线。
