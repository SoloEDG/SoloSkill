## gen-01：由无标注的镜像底片辨认星区和可安全归入计划的恒星

0-1。查遍 src，星表可按身份取得赤道坐标，点选只在已投影天体旁找最近点；无底片、镜像相机模型、对应关系搜索或证据留存。

历史最近对照：prompt.md:796。旧题先给锚点对齐两幅作品；本题没有对应关系，输出所有最多内点的离散身份及每类姿态见证。 同批对照：gen-02 同样用恒星，但输入点没有星名，结果是身份而非星等变化。

基线：可用 listBodies 与 equatorial 枚举目录、用 dome 的地点和时刻显示天区；projectAltAz 只投圆穹，不能反投针孔相片。

常规方案：枚举双/三星锚点、拟合一幅姿态，用二分匹配保留最多内点，再以最佳误差打破平局。匹配对给定姿态是正确的，但只在测点圆心拟合的有限姿态上做匹配，不能排除余下姿态内有更多可行配对。 距圈边 0.01 像素以下只允许标待定，若无法用边界证据排除竞争配对，不确认唯一。

仍需推导：在候选姿态生成中必须保留允许误差造成的相关旋转自由度，并能在两种手性上证明不存在更优匹配；离散配对相同的连续姿态只需一个见证。

可观察反例：把一张由目录合成的底片镜像，含两条划痕；在两个相似三角星群边缘放一颗误差圈跨候选位置的亮点，改变圈径并锁定星名。 每个可同时落圈的最优身份配置出现一次；锁定后保留的解均满足锁定；不共同确定的身份不能写入清单。 若错误简化：仅按最小平方残差保存第一认法，或合并两个姿态下各自成立的配对，得到没有真实相机能拍出的认星表。

少文件尝试：单一求解器即使能算出离散解，也收不到底片像素与容差编辑、无法使检索承担逐星约束、无法呈现与当前圆穹对应关系、无法用计划保存原片。把这些操作挤进旁置页面不改变现有星图和检索；直接读取它们的私有 DOM 则不符合模块职责。

## gen-02：从跨夜不完备差分测光记录确定目标星真实星等差的可行范围

0-1。目录提供单个内置星等；星图点选和清单添加仅记天体 id。src 无逐曝光测量、共同偏移、不稳定比较星或差分测光求解。

历史最近对照：prompt.md:2488。旧题对比歌声在对齐假设下的评分；本题恢复跨帧零点和不稳比较星，输出可证的星等差区间及端点见证。 同批对照：gen-01 寻找相机姿态和星名；这里星名已知、比较的是仪器星等。

基线：可复用目录 id、观测时间和星图点选；星表的固定亮度仅用于画大小，并不是比较星已知真实星等。

常规方案：逐帧分别拟合平均零点再扣除；或对每一对相邻帧先算不记身份的偏移区间，再沿跨夜路径相加。即使单帧界限正确，两步可能分别排除不同的比较星，拼出完全未被任何全簿解释支持的结果。

仍需推导：判定每个整簿共用坏星假设下的可行测量网络、消除统一零点的任意性，并分别投影后再求并集；需要同时恢复可行端点证据、辨别无界与矛盾。

可观察反例：两帧目标读数 10、11；比较甲读 10、10，乙读 12、14，误差均零，至多一颗比较星变光。 若甲稳定则目标差为 +1，若乙稳定则为 -1。只显示两个单点及各自见证，0 不可能。 若错误简化：返回 [-1,+1] 或逐夜剔除不同比较星，错误宣称零变化也可能。

少文件尝试：已有 sky 选择、clock 时刻、plan 只存 ID 的行和恢复器各自是不同的用户入口。仅在储存或一张表内写线性规划，无法从图建立、逐帧操作、回到端点证据时刻并从计划恢复；只改渲染又没有跨帧约束和测量归档。 单独存档的旁置表可绕过原恢复器，但不能同时实现星图端点读数、原检索证人过滤、现有计划中的多次测量、见证回放与联合求解。

P6：测量数据形状、一侧/双侧误差、联合归因、区间并集、可行端点还原、无界和矛盾分类，点星、改删、归档和恢复。。没有完整轨迹，不能判实际达标。

## feature-01：让现有观测名单挑出能保证拍到最多目标且张数最少的双夜镜头构图

Feature。现有 describePlan 为每个 ID 单独给几何高度、方位和十分钟趋势；扩展同一批成员到多天摄影的保证覆盖汇总并保留现有计划操作。

历史最近对照：prompt.md:958。旧题比较两套构图，没有离散候选、相机旋角、跨帧同一偏差与保证覆盖优化。 同批对照：feature-02 比较两站接触时刻，不选底片、不最大化目标覆盖。

基线：复用 bodyHorizontal、plan 的 bodyIds 和 site/clock 预览；星图采用圆形等距投影，不能代替底片针孔矩形。

常规方案：为每张底片取各偏差下覆盖的交集，再做集合覆盖。反向将所有可能覆盖先合并也不成立。逐张贪心选择增加最多颗数的画面，即使对每一偏差都正确计算也不能证明全局张数最少。

仍需推导：决定需要保留的跨帧覆盖状态和可剪去的候选；只有同一夜共享偏差，两夜必须允许独立，算法需维护可验证的全局上界与取景见证。

可观察反例：一颗星在同夜左偏时仅入甲、右偏时仅入乙；两片在不同可拍时刻。再把乙挪到另一夜。 同夜都选则两种偏差都有片；分夜后两边偏差可分别取到各自的漏拍值，目标不再有保证，清单给出漏拍组合。 若错误简化：先逐片取交集会错误拒绝同夜保证；把所有晚当作同一偏差又会错误接受分夜排法。

少文件尝试：只扩展 rows.ts 的逐星标记没有候选选择、共用偏差、星图构图输入和存档；在页面旁增求解器也不能自动更改现有名单、投影及其恢复。即使将场景几何与优化合为一个业务模块，仍有计划编辑、球面取景、时间地点联动、持久化等职责。

P6：跨夜相关不确定性几何、透视和地平筛选、有限预算全局求解与验证证人、天空选择中心、计划版本存取和对比。。没有完整轨迹，不能判实际达标。

## feature-02：扩展现有地点切换，以两站各自的日月视差解释日食接触与局部可见过程

Feature。基线 site 的 preset/坐标编辑替换单一 dome.site，地平变化不改日月地心方向，原月相图固定半径。新增两站共享一次查询的局地结果并保留当前定位能力。

历史最近对照：prompt.md:2430。旧题求脉冲通过器件后的时间门能量；本题求两站站心视半径、角距接触和共同可见重叠区域。 同批对照：feature-01 主产品是镜头组合，本题主产品为两站接触/可见时刻。

基线：moonEquatorial 给出月地距离，但 equatorial 丢掉该量；可复用教学轨道与换算而不能把地心视线直接套给两地。paintDome 的太阳/月亮半径为屏幕图标尺寸。

常规方案：每分钟比较两个圆心角距与半径和/差，有变号再二分，配合太阳中心上升判可见。加密到每秒仍会错过切点，外切时的符号不跨零；只要太阳中心低于地平就过滤，会删掉地平上已相交的两段圆弧。

仍需推导：选取能识别极小值、双根与未分辨区间的时域包围方案，并判定越过地平的是重叠区而非任一完整日面；数值误差边缘如何向用户给出诚实的时间窗。

可观察反例：构造两站模型，一站的最近中心距仅比外切半径和略小，短食在一个粗步长的中间；另一站最近值仍高于阈值。接触点附近太阳中心在地平下，而实际重叠边缘在上。 该站报告分辨得到的短接触或诚实的误差窗；另一站不能共享首站结果；日面中心未升不自动抹去可见重叠。 若错误简化：不变号就报两站无食，或给两站同一 UTC 接触列表；还可能误报整个地平下的月面重叠为可见。

少文件尝试：仅用原 scene/rows 接口没有站心距离和角半径、站对输入、双站显示和站别事件收藏。复用通用求根库也不能填补站心物理模型和可见重叠判定；把全套业务放在地点面板会绕开现有星图与清单。

P6：两站时空坐标、视半径、搜索并分类数值接触、求地平上交集、时间边界、真实比例的双图、归档身份。。没有完整轨迹，不能判实际达标。
